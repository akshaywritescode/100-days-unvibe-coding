# 100 Days of Unvibe Coding

A challenge for junior developers to build real skills — no AI assistance, just you and the code.

## What is this?

100 days. 100 projects. Pure HTML, CSS, and JavaScript.

This repo is a structured challenge that pushes you to actually *learn* web development by building things from scratch, not by prompting an AI to build them for you. Every line of code you write here is yours.

## Why no AI?

AI tools are useful, but leaning on them too early skips the fundamentals. Debugging, reading errors, understanding the DOM, writing CSS that actually works — these skills only come from doing the work yourself. This challenge is about building that foundation.

## The Rules

1. No AI code generation (ChatGPT, Copilot, Kiro, etc.)
2. No copying full solutions from the internet
3. You *can* read documentation, tutorials, and Stack Overflow answers — that's normal development
4. One project per day (or at your own pace, but keep moving)
5. Each project lives in its own folder: `day-001/`, `day-002/`, etc.
6. Commit your work daily

## Getting Started

1. Fork this repo
2. Create a folder for Day 1: `mkdir day-001`
3. Start building
4. Commit at the end of each session
5. Share your progress — tag it `#100DaysOfUnvibeCoding`
